Overview

§1. K-Democracy란 무엇인가

K-Democracy는 고팡(Gopang) AI 평행 세계의 입법 시스템입니다. 현실 세계의 국회나 주민투표에 대응하는 고팡 전용 규범 제·개정 메커니즘으로, 사용자가 제안한 아이디어를 AI가 완성된 안건으로 변환하고, 공정한 심사와 투표를 거쳐 고팡의 원칙·규칙에 즉시 반영합니다.

문제 1

대의 민주주의의 한계

선출 대표가 시민 대신 결정. 임기 중 책임 묻기 어려움. 전문성 부족으로 오결정 빈발.

문제 2

안건 작성 진입 장벽

법률·정책 문서 작성은 전문가 영역. 일반 시민의 아이디어가 공식 안건으로 이어지기 어려움.

문제 3

불투명한 의결 과정

의결 근거·과정이 비공개. 사후 검증 불가. 결과 조작 가능성 상존.

K-Democracy의 해결 방식

해결 1

직접 민주주의

모든 사용자가 직접 제안하고 의결합니다. 대표자 없이, 공헌도에 비례한 투표권으로 결정합니다.

해결 2

AI 안건 자동 완성

핵심 아이디어만 입력하면 DeepSeek V4 Pro가 제목·배경·찬반 논거·합리성 점수까지 자동 작성합니다.

해결 3

완전한 투명성

모든 안건·투표·의결 결과가 PDV에 기록되고 OpenHash에 앵커링됩니다. 위변조 원천 차단.

§2. AI 안건 자동 작성 시스템

K-Democracy의 핵심 기능입니다. 사용자는 아이디어를 자유롭게 입력하기만 하면 됩니다. 안건 분류, 법률 용어 정리, 논거 구성은 모두 AI가 수행합니다.

사용자 아이디어 입력 (자유 서술)
    │
    ▼
DeepSeek V4 Pro (gopang-proxy 경유)
    ├── 안건 분류 자동 결정 (경제/인프라/법률/거버넌스/보안)
    ├── 제목 생성 (30자 이내, 핵심 명확)
    ├── 요약 작성 (2~3문장)
    ├── 배경·근거 (300~500자, 논리적 구성)
    ├── 기대 효과 (3가지, 측정 가능)
    ├── 찬성 논거 (3가지, 심사 최적화)
    ├── 반대 논거·대응 (2~3가지 + 대응 방안)
    └── 합리성 점수 (1~10점 + 근거)
    │
    ▼
사용자 검토 → 안건 게재 → 1,000표 동의 확보 → 심사 상정

기술 스택

AI 모델

DeepSeek V4 Pro

gopang-proxy Cloudflare Worker를 경유하여 API 키를 서버 측에서 주입합니다. 클라이언트에 키가 노출되지 않습니다.

출력 형식

구조화된 JSON

8개 필드의 JSON을 강제 출력합니다. 잘린 JSON은 자동 복구 알고리즘(repairJson)으로 처리합니다.

입력 방식

멀티모달 입력

텍스트 입력, 음성 인식(Web Speech API), 카메라 촬영, 파일 첨부를 모두 지원합니다.

UX

단계별 진행 표시

9단계 진행 메시지와 프로그레스바로 실시간 상태를 표시합니다. 응답 완료 시 자동 스크롤.

안건 제목

분류
경제
요약
고팡 마켓에서 GDC로 결제하는 사용자에게 결제액의 1%를 GDC로 환급하는 캐시백 제도를 도입합니다. GDC POOL 운용 수익의 일부를 재원으로 하여, GDC 사용을 촉진하고 생태계 내 화폐 순환을 강화하기 위함입니다.
배경·근거
현재 고팡 마켓은 수수료 0% 구조로 차별화되어 있으나, GDC 사용을 유도하는 인센티브가 부재합니다. GDC POOL은 연 KOSPI Index ETF 운용으로 약 5% 수익을 창출 중이며, 이 중 20%를 캐시백 재원으로 배정하면 연 1% 수준의 지속 가능한 환원이 가능합니다. 이 구조는 사용자 인센티브, GDC 유통 증가, POOL 자산 회전율 향상의 삼중 효과를 가져옵니다.
기대 효과
1. GDC 결제 비중 최소 30% 이상 증가
2. 월간 활성 사용자(MAU) 15% 이상 성장
3. GDC POOL 자산 연간 회전율 약 20% 개선
찬성 논거
1. 외부 자본 없이 기존 POOL 수익으로 충당 — 비영리 원칙 부합
2. PDV 기록 + OpenHash 앵커링으로 완전한 투명성 보장
3. 3개월 성과 보고를 K-Democracy에 공개 — 데이터 기반 정책 평가
반대·대응
반대: POOL 수익률 하락 시 지속가능성 훼손
→ 대응: 수익률 3% 이하 시 캐시백 비율 자동 조정 스마트 계약 반영

반대: 소액 반복 결제 어뷰징 우려
→ 대응: 월 최소 100 GDC 조건 + 동일 지갑 반복 결제 탐지 알고리즘

반대: 30일 사용 제한이 UX 저해
→ 대응: 3개월차 성과 보고 시 60일 완화 검토 및 알림 서비스 제공
합리성
8 / 10 GDC POOL 실존 수익 기반, PDV/OpenHash 투명성 설계 우수. 시장 변동성 리스크 관리 모델 보완 필요.

§4. 안건 심사 파이프라인

1,000표 동의를 획득한 안건은 8단계 AI 심사 파이프라인을 거칩니다. 각 단계는 독립된 AI 인스턴스가 담당하며, 인스턴스 간 정보 교환은 설계상 차단됩니다.

SP-01  사용자 DB 구성 (PDV 공개 데이터 수집)
    ↓
SP-02  안건 분류 (유형·난이도·전문성 태깅)
    ↓
SP-03  심사위원단 선발 (적격성·이해충돌·다양성 기준)
    ↓
SP-04  찬성발의단 (독립 인스턴스 A)  ‖  SP-05  반대심사단 (독립 인스턴스 B)
              ⛔ 인스턴스 간 정보 교환 완전 차단
    ↓
SP-06  심의위원회 (DeepSeek V4 Pro · 인스턴스 C)
         찬반 논거 동시 검토 → 가결 / 부결 / 수정 권고
    ↓
SP-07  교차 검증 (Claude Opus · 독립 모델)
         심의결정의 유효성·정당성 검증
    ↓
SP-08  인간 심사위원단 최종 결정
         AI 판단에 구속되지 않는 독립적 결정권
    ↓
    고팡 원칙·규칙 즉시 반영 → OpenHash 앵커링

인간 위원단의 독립성

AI의 심의결정은 참고 자료일 뿐, 인간 위원단의 최종 결정에 구속력을 갖지 않습니다. 위원단은 AI가 제시하지 않은 새로운 근거를 들어 결정할 수 있으며, 모든 결정은 OpenHash에 영구 기록됩니다.

§7. 기술 인프라

OpenHash

위변조 불가 분산원장

SHA-256 기반 5계층(L1~L5) 분산원장. 모든 안건·투표·의결 결과를 앵커링. 에너지 소비 블록체인 대비 98.5% 절감.

PDV

사용자 데이터 금고

Private Data Vault. 모든 의결 참여 기록을 6하원칙으로 사용자 기기에 암호화 저장. 대규모 해킹 원천 차단.

gopang-proxy

Cloudflare Worker API 프록시

DeepSeek V4 Pro, Claude Opus 등 AI 모델의 API 키를 서버 측에서 주입. 허용 도메인 화이트리스트 관리.

Supabase

PDV 로그 백업

pdv_log 테이블에 6하원칙 요약 저장. WebAuthn 인증 정보 관리. 실시간 동기화.
